Ejercicio 1:

1. ¿Qué es CSS y para qué se usa?

CSS (Cascading Style Sheets) es un lenguaje de estilos que se utiliza para definir la apariencia visual de un documento HTML y se 
usa para controlar cómo se ven los elementos de una página web

2. CSS utiliza reglas para las declaraciones de estilo, ¿cómo funcionan?

Partes de una regla:
Selector: Indica a qué elemento HTML se aplica el estilo. Ej: p, h1, .clase, #id
Declaración: Está dentro de {} y define el estilo.
Propiedad: Qué aspecto se modifica. Ej: color, font-size, margin
Valor: Cómo se modifica la propiedad. Ej: red, 16px, center

3. ¿Cuáles son las tres formas de dar estilo a un documento?
En línea (inline): Se aplica directamente en la etiqueta HTML con el atributo style.
Interno (internal o embebido): Se escribe dentro de la etiqueta <style> en el <head> del documento.
Externo (external): Se usa un archivo .css separado y se vincula con <link>.

4. ¿ Cuáles son los distintos tipos de selectores más utilizados? Ejemplifique cada uno.
Selector de elemento (etiqueta): Aplica a todas las etiquetas de ese tipo.
Ej: p {
  color: blue;
}

Selector de clase (.): Aplica a elementos con una clase específica.
Ej: .destacado {
  color: red;
}

Selector de id (#): Aplica a un elemento con un id único.
Ej: #titulo {
  font-size: 24px;
}

Selector universal (*): Aplica a todos los elementos.
Ej: * {
  margin: 0;
}

Selector descendente: Aplica a elementos dentro de otros.
Ej: div p {
  color: green;
}

Selector de hijo directo (>): Aplica solo a hijos directos.
Ej: div > p {
  color: orange;
}

Selector de atributo: Aplica según atributos.
Ej: input[type="text"] {
  border: 1px solid black;
}

5. ¿Qué es una pseudo-clase? Cuáles son las más utilizadas aplicadas a vínculos?
Una pseudo-clase en CSS es una palabra clave que se agrega a un selector para definir un estado especial de un elemento.
Las más utilizadas son: :link (Enlace no visitado), :visited (Enlace ya visitado), :hover (Cuando el mouse pasa por encima)
:active (Cuando el enlace está siendo clickeado)

6. ¿Qué es la herencia?
La herencia es el mecanismo por el cual algunas propiedades de estilo se transmiten automáticamente 
de un elemento padre a sus elementos hijos.

7. ¿En qué consiste el proceso denominado cascada?
La cascada es el mecanismo que utiliza CSS para determinar qué estilo se aplica 
a un elemento cuando existen múltiples reglas que podrían afectarlo.
Se basa en: Prioridad, especificidad, orden de aparición.

Ejercicio 5:
En cada caso, declarar una regla CSS que produzca el siguiente efecto:

1. Los textos enfatizados dentro de cualquier título deben ser rojos.
h1 em, h2 em, h3 em, h4 em, h5 em, h6 em {
  color: red;
}

2. Cualquier elemento que tenga asignado el atributo "href" y que esté dentro de cualquier párrafo que a
su vez esté dentro de un bloque debe ser color negro.
div p [href] {
  color: black;
}

3. El texto de las listas no ordenadas que estén dentro del bloque identificado como “ultimo” debe ser
amarillo pero si es un enlace a otra página debe ser azul.
#ultimo ul {
  color: yellow;
}

#ultimo ul a {
  color: blue;
}

4. Los elementos identificados como “importante” dentro de cualquier bloque deben ser verdes, pero si
están dentro de un título deben ser rojos.
div #importante {
  color: green;
}

h1 #importante,
h2 #importante,
h3 #importante,
h4 #importante,
h5 #importante,
h6 #importante {
  color: red;
}

5. Todos los elementos h1 que especifique el atributo title, cualquiera que sea su valor, deben ser azules.
h1[title] {
  color: blue;
}

6. El color de los enlaces en las listas ordenadas debe ser azul para los enlaces aún no visitados, y violeta
para los ya visitados y, además, no deben aparecer subrayados.

  text-decoration: none;
}
